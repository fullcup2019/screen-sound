# 🎵 Screen Sound

Primeiro projeto de consola desenvolvido em C# como parte do curso da Alura. A aplicação explora conceitos fundamentais da linguagem C#, como funções, laços de repetição e dicionários[cite: 2].

---

## 🚀 Tecnologias Utilizadas

* **C#** (.NET Framework / .NET Core)
* **Visual Studio / VS Code**[cite: 2]

---

## 🎯 Funcionalidades e Conceitos Aplicados

* Uso de **funções** para organização do fluxo do programa[cite: 2].
* Estruturas de repetição (**loops**) para navegação em menus e manipulação de coleções[cite: 2].
* **Dicionários (`Dictionary<TKey, TValue>`)** para armazenamento e consulta dinâmica de dados[cite: 2].
